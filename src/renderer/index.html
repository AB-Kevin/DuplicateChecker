Sharing

Shown to others using the same data folder.

The host imports new files from the inbox and saves everyone's decisions to Database.xlsx and Duplicates.xlsx. Everyone else reviews and sends their decisions to it. Only one computer using the data folder should be the host, and its app needs to be open for decisions to be saved.

Duplicate matching

An entry is flagged for review when every column in the first list matches an existing entry, and enough of the columns in the second list match as well. Either list can be left empty. These settings are stored in the data folder, so anyone using it compares entries the same way.

Columns from files dropped into the inbox are listed automatically. Column names are matched without regard to capitals or spacing.

1. Columns that must always match

Every column checked here has to match.

2. Columns where some must match

Current rule

Dates and amounts are compared by value, so 3/15/2026 matches 2026-03-15 and $1,250.00 matches 1250. Blank cells never count as a match.

Database retention

days

Older entries are removed from Database.xlsx at the next import or saved review, and new files are no longer compared against them. Enter 0 to keep entries indefinitely.

Clear all data

Start over with an empty database. This empties Database.xlsx and Duplicates.xlsx, removes every entry waiting for review, and clears the activity log so the same files can be imported again. Settings, the inbox and the Processed folder are not changed.

Only the host computer can clear all data.
